# 🎓 Serverless Study Cards

> A full-stack serverless web application for creating, viewing, and managing digital flashcards — built entirely on AWS (S3, API Gateway, Lambda, DynamoDB).

## 🛠️ Tech Stack

- **Frontend Hosting:** Amazon S3 (Static Website Hosting)
- **API Layer:** Amazon API Gateway (REST API)
- **Backend Compute:** AWS Lambda (Python)
- **Database:** Amazon DynamoDB (NoSQL)
- **Frontend:** HTML, CSS, JavaScript

---

## ✨ Features

- [ ] Create a new flashcard (question + answer)
- [ ] View all flashcards
- [ ] Edit an existing flashcard
- [ ] Delete a flashcard
